# AI Terminal

A simple desktop terminal application built with Python and Tkinter.

## Prerequisites

This application uses `tkinter` for its graphical interface. You might need to install the corresponding system package if it's not already present. The command varies depending on your operating system and package manager:

*   **Debian/Ubuntu:** `sudo apt-get update && sudo apt-get install python3-tk`
*   **Fedora:** `sudo dnf install python3-tkinter`
*   **Arch Linux:** `sudo pacman -S tk`
*   **macOS (using Homebrew):** `brew install python-tk` (if using Homebrew's Python)

## Setup

1. Clone the repository (or create the files).
2. Navigate to the `ai_terminal` directory.
3. Activate the virtual environment: `source .venv/bin/activate`
4. Run the application: `python main.py`
